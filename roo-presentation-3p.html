02 / 03  ·  Roo 소개

Roo — 직접 일하는 AI 동료

ChatGPT가 옆에서 조언한다면, Roo는 직접 실행합니다.

ChatGPT가 "옆에서 조언해주는 멘토"라면, Roo는 "내 컴퓨터에서 직접 작업하는 동료"입니다.
🗣️
한국어로 편하게 대화
"이 함수 이름 더 명확하게 바꿔줘"처럼 일상 언어로 요청하면 됩니다.
📂
파일을 직접 열고 수정
복붙 없이 Roo가 내 PC의 파일을 직접 열고, 고치고, 저장합니다.
⚡
터미널 명령도 자동 실행
"테스트 돌려줘" 요청을 받으면 명령어를 직접 실행하고 결과까지 확인합니다.
🌐 ChatGPT / 웹 AI 🤖 Roo
파일 수정 ✗ 복사·붙여넣기 직접 ✓ 직접 열고 수정
실행 ✗ 터미널은 직접 ✓ 자동 실행
안전장치 — ✓ Approve 전엔 변경 없음
💡 핵심: Approve 버튼을 누르기 전까지는 아무것도 바뀌지 않아 안전합니다.

1

무료

Ctrl+Shift+X (Mac: Cmd+Shift+X) → 검색창에 Roo Code 입력 → Install
3
사내 API 키 입력
go/ums 에서 키 발급 후 Roo 설정 화면에 붙여넣기 — 토큰 무제한, 별도 비용 없음
