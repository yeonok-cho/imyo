02 / 10  ·  LLM 개념

AI의 두뇌, LLM이란?

Large Language Model — 대규모 언어 모델

① 어떻게 만들어졌나
수백억 개의 글을 읽다
인터넷의 방대한 텍스트(책, 코드, 뉴스, 논문 등)를 읽고, "다음에 올 단어가 뭘지" 반복 학습한 모델입니다. 사람이 글을 읽고 패턴을 익히는 것과 비슷하지만, 규모가 수천 배 큽니다.
② 어떻게 동작하나
문맥을 이해해서 답한다
질문을 입력하면 → 학습한 패턴을 바탕으로 → 가장 자연스러운 답을 단어 하나씩 생성합니다. 계산기처럼 정해진 공식이 아니라, 문맥을 이해해서 대답합니다.
③ 한계도 있다
완벽하지 않습니다
학습 데이터 이후의 사실은 모름 (지식 컷오프)
가끔 틀린 정보를 자신 있게 말함 (할루시네이션)
기본적으로 "대화"만 가능 → 파일을 직접 바꾸진 못함
💡 핵심 한 줄: LLM은 엄청나게 많은 글을 읽고 자란 "텍스트 전문가"입니다.

복붙의 굴레
코드를 올리고 → 답 받고 → 다시 파일에 넣는 과정을 매번 반복해야 합니다. 파일이 10개라면 10번 반복입니다.
🕶️
프로젝트 전체를 모른다
웹 서비스는 지금 붙여넣은 코드만 봅니다. "다른 파일이랑 연결이 안 돼요"라는 문제는 AI가 알 수 없습니다.
🖐️
실행은 내가 직접
AI가 "이렇게 해보세요"라고 알려줘도, 터미널을 열어서 명령어를 치는 건 여전히 내 몫입니다.

05 / 10  ·  Roo 소개

Roo — AI가 직접 일하는 코딩 에이전트

ChatGPT가 "옆에서 조언해주는 멘토"라면,
Roo는 "실제로 키보드를 두드리는 주니어 개발자"입니다.
🗣️
자연어 대화 (한국어 가능)
"이 함수 이름 좀 더 명확하게 바꿔줘"처럼 일상 언어로 요청하면 됩니다. 코딩 문법을 몰라도 대화가 가능합니다.
📂
로컬 파일 직접 수정
파일을 복사해서 붙여넣을 필요 없이, Roo가 내 PC의 파일을 직접 열고 수정합니다. 저장까지 해줍니다.
⚡
터미널 명령 자동 실행
"테스트 돌려줘", "패키지 설치해줘" 요청을 받으면 터미널 명령어를 직접 입력하고 실행합니다. 결과도 읽고 이어서 작업합니다.
🗂️
멀티 파일 작업
파일 하나가 아니라 프로젝트 전체를 이해합니다. A 파일을 바꾸면 연결된 B, C 파일도 함께 수정합니다.
🖼️
멀티모달 지원
스크린샷이나 UI 디자인 이미지를 보여주면서 "이대로 만들어줘"라고 요청할 수 있습니다. 텍스트뿐 아니라 이미지도 이해합니다.
🔒
로컬 우선 보안
내 코드가 외부 서버로 전송되지 않도록 로컬 모델과 연결할 수 있습니다. 사내 보안 정책에 맞게 운용 가능합니다.

Roo 시작하기 — 4단계면 충분합니다

설치 완료까지 약 10분. 한 번만 하면 됩니다.

1
VS Code 설치
code.visualstudio.com 에서 무료로 다운로드합니다.
전 세계 개발자의 73%가 쓰는 코드 편집기로, 설치 파일을 실행하면 됩니다.
무료
2
Extensions 탭 열기
VS Code 실행 후 Ctrl+Shift+X (Mac: Cmd+Shift+X)를 누르면 확장 프로그램 탭이 열립니다.
앱스토어처럼 필요한 도구를 검색해서 설치하는 공간입니다.
3
"Roo Code" 검색 후 설치
검색창에 Roo Code 입력 후 Install 버튼 클릭.
설치 완료까지 1분 이내입니다.
오픈소스
4
API 키 입력 — 사내 API 사용
사내 API를 사용합니다 → 토큰 무제한, 별도 비용 없음
설정 방법: go/ums 에서 키 발급 후 Roo 설정 화면에 붙여넣기
💡 팁: 설치 중 오류가 생기면 편하게 문의해 주세요. 함께 해결합니다.

이런 상황에서 써보세요

실제 업무 시나리오별 활용법입니다.

📊
시나리오 A — 데이터 분석가
"이 CSV 파일 읽어서 월별 매출 합계 뽑는 코드 만들어줘"
pandas를 모르더라도 요청만 하면 코드를 작성하고 실행까지 합니다. 결과 확인 후 "그래프도 그려줘"로 이어가면 됩니다.
기존: 구글 검색 + 스택오버플로우 30분 → Roo: 3분
📝
시나리오 B — 문서 자동 작성
"이 함수들 보고 API 명세서 마크다운으로 만들어줘"
코드 파일을 직접 읽고 함수 설명, 파라미터, 반환값을 자동으로 문서화합니다.
기존: 수작업 2시간 → Roo: 10분
🐛
시나리오 C — 디버깅
"테스트 돌렸더니 이 오류 났어. 원인 찾아서 고쳐줘"
오류 메시지를 붙여넣으면 관련 파일을 전부 뒤져 원인을 찾고 수정합니다. 터미널에서 테스트 재실행까지 자동으로 합니다.
기존: 원인 파악 1시간 → Roo: 10~15분
